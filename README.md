# machine-learning-getting-started

## Getting started

Create a virtual environment.

```shell
python3 -m venv .venv
```

Activate the virtual environment.

```shell
source .venv/bin/activate
```

Install the packages.

```shell
pip install -r requirements.txt
```

To deactivate virtual environment when you are done with your work.

```shell
deactivate
```

## Start Jupyter notebook

Run the following command in the terminal, and it will start Jupyter notebook in your browser.

```shell
jupyter notebook
```
